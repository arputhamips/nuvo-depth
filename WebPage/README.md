# Nuvo Vision One shopping page

This is a standalone, framework-free product page in the repository root. It is separate from the device console in `../web/`. Serve this folder as a static site; `index.html` is the only page. For local preview, run `python -m http.server 8000 --directory WebPage` from the repository root and open `http://localhost:8000/`.

## Checkout configuration

The Raspberry Pi 5 configuration is wired to the live Stripe Payment Link in `store-config.js` at $229 USD. At the last read-only checkout review, the link still displayed the previous product name. Rename the Stripe product to **Nuvo Vision One (Raspberry Pi 5)** and verify the checkout title, Case Color dropdown, United States shipping-address form, and buyer-facing merchant name before publishing externally. Stripe previously displayed **Fable Interactive Inc.** as the merchant name. The site itself never collects payment information or contains a Stripe secret key.

Case swatches on the page preview the finish only. The buyer chooses the binding color in Stripe checkout. The picker shows Raspberry Pi 5 at $229, BYO Compute at $159, and Luckfox Aura at $199. BYO and Aura can be selected to preview all three case colors, but their purchase button stays disabled until each has its own live Payment Link in `store-config.js`. Aura is marked coming soon.

## Specification sources

The IMX296 color/global-shutter, 1456 × 1088 effective resolution, 1/2.9-type format, and 3.45 µm pixel facts are from [Sony's IMX296LQR flyer](https://www.sony-semicon.com/files/62/flyer_industry/IMX296LQR_Flye.pdf). Pi 5 implementation and default 728 × 544 / 10 Hz capture-target figures come from `README.md`, `docs/pi5-depth-100mm-profile.md`, `docs/production-implementation-status.md`, and `config/nuvo_pi5_depth_100mm.yaml`. The full-resolution Pi 5 10 Hz depth goal, up-to-15 Hz full-sensor capture figure, additional profiles, and Aura 728 × 544 / 10 Hz goal are owner-provided product targets, not qualified sustained performance. The Aura compute name and RV1126B designation match [Luckfox's board specification](https://wiki.luckfox.com/Luckfox-Aura/Introduction/). The 100 mm baseline is nominal. Production pre-calibration and built-in profiles are planned; the checked-in calibration remains provisional and per-unit acceptance is pending.

The [IMX296 color-camera module listing](https://www.inno-maker.com/product/cam-imx296color/) lists an M12 lens and holder, a C/CS holder option, adjustable focus and an IR filter for the color assembly. The owner confirmed that Vision One uses M12 wide-angle lenses rated at 140° field of view. This is a nominal lens rating, with no horizontal/vertical/diagonal axis specified by the owner; it is not a measured rectified stereo field of view. The repository's calibration seed is provisional, so effective coverage remains pending final measured calibration. The owner's linked mono-camera listing was used as a reference, but the color variant is the relevant source for Vision One.

The Pi 5 gateway documents wired Ethernet transport. [Luckfox's Aura board specification](https://wiki.luckfox.com/Luckfox-Aura/Introduction/) confirms a Gigabit Ethernet interface and a USB 3.0 OTG Type-C port, but its standard power input is separate. Single-cable USB 3 power-plus-data operation is an owner-proposed product design option, not a validated stock-board capability; it requires an integrated power design, host compatibility checks, and transport qualification. The page labels Aura transport integration and this single-cable mode accordingly.

The attached Slate design kit informed the Hanken Grotesk type, graphite/blue palette, compact radii, spacing, ruled specifications, and product-gallery/buy-panel layout. The header, footer, and favicon reuse the ring-and-crescent logo mark drawn in `../web/styles.css` alongside the **Nuvo** company wordmark; **Vision One** appears separately as the product name. The storefront retains its blue palette and does not reuse the work-in-progress device-console layout or the Slate mower's copy and photos.

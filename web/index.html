CAPTURE CONTROL

Exposure & trigger

Read-only capture policy. The running gateway does not yet expose safe, live sensor controls.

Hardware synchronization

The experimental Pi 5 profile requests one external XTRIG pulse per stereo pair at 60 Hz. Pulse-width and lighting validation are still required to diagnose the ISP brightness swings.

Manual exposure

The native capture path disables AE and AWB and requests matched shutter and analogue gain. The 60-frame trace reported a fixed 7,999 µs exposure and near-constant gain; the brightness flicker was present before depth matching.

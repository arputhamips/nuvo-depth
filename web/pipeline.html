Canvas controls and keyboard help

Drag a node's heading bar to move it. The arrow button opens or closes settings independently. Use the fixed Node controls above the canvas when zoomed out; Focus node returns to readable zoom. Move node also provides direction buttons and exact coordinates, so dragging is optional. On small screens, node settings open in a sheet with visible Apply and Discard controls. Close settings or Escape returns to the node.

Tap the output socket on a node's right edge, choose a product, then tap an input socket on the destination's left edge or choose a destination and Connect. You can also drag between these ports. The small socket dots have larger invisible hit areas; the pointer becomes a crosshair over a wire target. Select an editable wire to change its source or destination, or disconnect it. Dragging an existing wire end is also available with a mouse. Occupied destinations are protected from accidental replacement. Dropping outside a valid port keeps the existing wire.

Tab reaches all controls. Enter or Space activates a control; a selected node can also move with arrow keys. Escape cancels the connection gesture or closes movement controls. Required stage wiring stays locked. Route edits stay pending until Apply outputs; Undo restores a previous route.
